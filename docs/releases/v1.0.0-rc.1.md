# Sky v1.0.0-rc.1

This candidate previews the Sky 1.x command and data contracts. It includes aircraft lookups, watchlists, bounded polling, local observation history, and JSON and CSV output. Commercial flight status remains deferred under the $0 provider budget.

Download the ZIP and SHA-256 sidecar for Linux amd64, Apple Silicon macOS, or Windows amd64. Verify the checksum before extraction and run `sky --version`. See the [installation guide](https://github.com/Mickyj70/sky/blob/v1.0.0-rc.1/docs/BINARY_INSTALL.md).

Both SQLite databases retain schema 1. Back up watchlist and history separately before switching binaries. To roll back, restore compatible snapshots into a fresh directory and select it with the earlier executable. See the [recovery guide](https://github.com/Mickyj70/sky/blob/v1.0.0-rc.1/docs/RECOVERY.md).

Try the candidate and report compatibility or installation regressions before stable acceptance. See the [proposed 1.x policy](https://github.com/Mickyj70/sky/blob/v1.0.0-rc.1/docs/COMPATIBILITY.md).
