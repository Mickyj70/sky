# Sky v0.5.0-rc.1

This distribution prerelease packages Sky for Linux amd64, Apple Silicon macOS and Windows amd64. The version follows the M4 roadmap. Commercial flight status remains deferred under the $0 provider budget.

Download the ZIP for your platform and its SHA-256 sidecar. Each archive includes the executable, license notices and the exact build revision in `build.json`. Verify the checksum before extracting, then run `sky --version` and expect `sky version 0.5.0-rc.1`. See the [installation guide](../BINARY_INSTALL.md).

Existing aircraft lookups, bounded watch runs and local history are included. Watchlist and history databases retain schema 1. Keep the previous binary and back up both databases separately before upgrading. See the [recovery guide](../RECOVERY.md).
